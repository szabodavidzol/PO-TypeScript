Rendezvénykezelő Rendszer
OOP alapú TypeScript projekt

A projekt egy objektumorientált TypeScript alkalmazás, amely rendezvények kezelésére szolgál.
A rendszer képes:

rendezvények létrehozására, szerkesztésére, törlésére

résztvevők regisztrálására és rendezvényhez adására

rendezvények tematikus csoportosítására

adatok lekérdezésére (rendezvények, résztvevők)

A projekt opcionálisan tartalmaz:

dekorátorokat (logolás)

egyszerű aszinkron működést hibakezelés céljából
